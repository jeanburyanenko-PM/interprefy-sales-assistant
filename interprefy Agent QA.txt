# Interprefy Agent — Sales Guidelines

## Definition
Interprefy Agent is a self-service AI translation solution designed for online meetings.

It is best suited for customers who need flexibility, autonomy, and cost efficiency.

---

## When to Sell Interprefy Agent

Sell Interprefy Agent when:
- The customer needs a self-service solution
- The customer has limited budget
- The customer does not require full Interprefy support
- The use case is an online meeting (not a large-scale event)

Alternative use:
- Can be used for hybrid sessions if budget is limited
- Requires acceptance of QR code / URL-based delivery
- One Agent email is required per room/session

---

## Platform Availability

Interprefy Agent works with:
- Microsoft Teams
- Zoom
- Google Meet
- Webex

---

## Setup for Sales / Demos

- The Agent requires a dedicated email address
- This must be requested via a Service Desk (SD) ticket
- The Event ID must be provided when requesting the Agent email

Use case:
- Can be used in customer demos (including Teams demos)

---

## Support Model

- Typically used without Interprefy support (self-service)
- Optional support can be provided if required
- If support is included, it must be priced in the quote

---

## Language Capabilities

- Up to 10 languages with automatic language switching
- Up to 25 languages with manual language switching

Language control:
- Automatic switching is supported
- Manual switching is also supported
- The client is responsible for switching languages (not via Teams/Zoom UI)

---

## Positioning vs Other Solutions

Interprefy Agent:
- Self-service
- Lower cost
- More flexible
- Less operational support

Compared to Inject:
- Agent is better for smaller, budget-sensitive use cases
- Inject is better for fully managed, high-touch scenarios

---

## IMPORTANT

- Interprefy Agent is NOT designed for large-scale events
- It is primarily designed for meetings
- It requires client autonomy and basic technical handling
