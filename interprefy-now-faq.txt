# Interprefy Now — FAQ

## Definition
Interprefy Now is a mobile-based AI translation solution for multilingual meetings (up to 100 participants).

- Provides real-time translated audio and captions
- Works for both in-person and remote meetings
- Peer-to-peer: each participant speaks and listens via their own device
- No AV equipment required

---

## Key Value
- Instant multilingual communication
- No setup or hardware required
- Suitable for face-to-face and simple online meetings
- Can complement existing meeting platforms (audio replacement)

---

## Requirements

### Devices
- Smartphone per participant (mandatory)
- Runs inside Interprefy mobile app
- Not available on desktop

### Audio
- Supported: earpiece, headphones, earbuds, AirPods
- Not supported: phone loudspeaker (disabled to prevent feedback)

### Connectivity
- Stable internet required (Wi-Fi or mobile)
- Stability > bandwidth
- Recommended to avoid network congestion

---

---

## How It Works

- Each user joins via mobile app
- Selects preferred language
- One speaker at a time (controlled microphone)
- Real-time translation delivered as:
  - Audio
  - Captions

---

## User Experience

### General
- Captions always enabled (including original language)
- Users can scroll caption history
- Language preference is saved

### Participation
- All users must install and use the app
- Each user selects their own language

### Speaking Logic
- Only one microphone active at a time
- Requires structured turn-taking

---

## Meeting Modes

- In-person meetings
- Remote voice-only meetings
- Hybrid (used alongside platforms like Teams)

---

## Integration Usage

- Can run alongside meeting platforms
- Typical setup:
  - Laptop/tablet → video + chat
  - Phone → audio + translation

---

## Accessibility

- Captions in translated and original language
- Amplified audio via device
- Useful for hearing-impaired users

---

## Transcripts & Recording

- No recording available
- Transcripts:
  - Available for Host users only
  - Generated per session
  - Downloadable after session
  - Language depends on user settings

---

## Limitations

- Mobile-only (no PC/laptop)
- No simultaneous speakers
- No recording
- Requires stable network
- Audio-only (no video)

---

## Language Behavior

- No pre-configuration required
- All languages available by default
- Language must remain consistent during speech
- Late joiners can select language instantly
- System remembers last used languages

---

## Use Cases

- Remote discussions

## Positioning

Interprefy Now is best suited for:
- Fast, spontaneous multilingual communication
- Low-complexity setups
- Mobile-first environments
